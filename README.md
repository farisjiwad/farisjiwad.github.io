# Faris Jiwad's research website

An Astro site for research interests and projects.

```sh
npm ci
npm run build
npm run preview
```

Push changes to `main` to run the included Pages deployment workflow. In this repository's **Settings → Pages**, set the source to **GitHub Actions**; the existing branch-based Jekyll deployment does not build Astro.

The Research Radar project is maintained separately at [farisjiwad/research-radar](https://github.com/farisjiwad/research-radar). Its link on the homepage will work once GitHub Pages is enabled for that repository and its workflow succeeds. Its dataset is refreshed independently of this site.
